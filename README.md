# Portfolio

Osobiste portfolio UI/UX designera — statyczna strona w HTML, CSS i JavaScript.

## Funkcje

- Hero z efektem rozpraszania pikseli (canvas, fizyka sprężyny)
- Przełącznik języka PL / EN
- Własny kursor w sekcji hero
- Animacje pojawiania się elementów przy przewijaniu
- Formularz kontaktowy w oknie modalnym (wysyłka na e-mail przez Formspree)
- Responsywny układ

## Technologie

HTML5 · CSS3 · JavaScript (vanilla) · Figma

## Struktura

```
.
├── index.html
├── projects.html
├── assets/
│   ├── css/style.css
│   ├── js/main.js
│   ├── js/projects.js
│   └── img/
└── README.md
```

## Uruchomienie lokalnie

Otwórz `index.html` w przeglądarce. Do przetestowania formularza kontaktowego
potrzebny jest działający endpoint Formspree (patrz niżej).

## Formularz kontaktowy

W `index.html` zamień `TWOJ_ID` w atrybucie `action` formularza na własny
identyfikator z [formspree.io](https://formspree.io).
